Everything You Need

From connection management to advanced terminal features

🔒

SSH Key Authentication

Generate, import, and manage SSH keys. Support for RSA, ECDSA, and Ed25519 with encrypted storage.

🔒

TOTP Two-Factor Auth

Built-in TOTP token manager. Auto-generate 2FA codes linked to your hosts, one-tap fill in terminal.

🛡

Secure Storage

AES-256 encryption for sensitive data, keys stored in system secure chip (Keychain/Keystore), biometric unlock protection.

📤

trzsz File Transfer

Upload and download files with trz/tsz commands. Fully compatible with tmux sessions.

📝

Script Editor

Built-in code editor with syntax highlighting. Edit remote files in-place via SFTP without extra tools.

👁

File Preview

Preview PDF, Excel, and images; edit text files online; calculate file hash (MD5/SHA1/SHA256).

🎨

Vertical Color Bar

Left-side color bar distinguishes user input from server output. Quickly locate command boundaries in long logs.

🔬

Server Monitor

Real-time CPU, memory, disk, load & process monitoring for SSH sessions. Kill processes and custom refresh interval.

🔗

Proxy Jump

Seamlessly connect through bastion hosts and jump servers with multi-hop proxy chain support.

🔍

Terminal Search

Find anything in your terminal output with real-time search and highlight.

📱

Gesture Zoom

Pinch to zoom the terminal for the perfect text size. Comfortable coding on any screen.

📄

Select to Copy

Intuitive text selection with copy/paste. Long press to select, drag to extend.

∞

Unlimited Hosts

No artificial limits on host count. Manage all your servers without restrictions or hidden fees.

📳

QR Code Sharing

Share host configurations instantly via QR code. Scan to import on another device.

🎨

Multi-Theme Support

Built-in dark and light themes plus custom color schemes. Your terminal, your style.

Native tmux Integration

Full tmux support built right in — not just compatibility, but deep integration that makes tmux feel native on mobile.

  • Visual window tab bar for quick switching
  • Split-pane view support
  • Custom tmux theme styling
  • Background keep-alive for long sessions

Mosh — Mobile Shell

Switch between SSH and Mosh protocols. Mosh handles intermittent connections, roaming, and high-latency networks gracefully.

  • Smart protocol auto-detection
  • Seamless network roaming
  • Instant response on high-latency links
  • Automatic reconnection

Multi-Session & File Transfer

Work with multiple servers simultaneously. Browse files over SFTP and transfer with network-aware optimization.

  • Multi-session tab management
  • Built-in SFTP file browser
  • Local & remote port forwarding
  • Network-aware transfer optimization

Quick Commands & Shortcuts

Save your frequently used commands and share configurations via QR code. Built-in keyboard shortcuts for efficient mobile input.

  • Custom quick command library
  • QR code config sharing
  • SSH key management hub
  • Smart keyboard shortcut bar

Data & Sync

Your configurations travel with you. iCloud sync on iOS, import/export on all platforms, and session snapshots for quick recovery.

  • iCloud sync (iOS)
  • Config import & export
  • Session snapshot & restore
