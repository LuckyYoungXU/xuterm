XuTerm (далее «это Приложение») серьёзно относится к вашей конфиденциальности. Настоящая Политика конфиденциальности описывает, как мы собираем, используем, храним и защищаем вашу личную информацию.

Основное обязательство: Это Приложение не собирает, не загружает и не передаёт вашу личную информацию каким-либо третьим лицам. Все данные хранятся только на вашем локальном устройстве.

1. Информация, которую мы собираем

Это Приложение является инструментом SSH терминального клиента. Все данные хранятся локально на вашем устройстве. Мы не собираем, не загружаем и не передаём вашу личную информацию.

1.1 Информация, которую вы предоставляете

  • Данные SSH-подключения: адрес хоста, порт, имя пользователя, пароль/ключ (используются только для установления SSH-соединений, хранятся локально)
  • Секрет TOTP двухфакторной аутентификации: используется только для генерации кодов подтверждения, хранится локально
  • Конфигурация быстрых команд: ваши пользовательские быстрые команды (хранятся только локально)
  • Правила перенаправления портов: настроенные вами правила перенаправления портов (хранятся только локально)
  • Настройки терминала: шрифт, тема, горячие клавиши и другие настройки (хранятся только локально)

1.2 Автоматически собираемая информация

  • Это Приложение не собирает автоматически информацию об устройстве, данные о местоположении или данные о поведении использования.
  • Это Приложение не содержит сторонних SDK аналитики.
  • Это Приложение не использует рекламные SDK или инструменты отслеживания.

2. Как мы используем вашу информацию

Ваша информация используется только в следующих целях:

  1. Установка и управление SSH / Mosh-соединениями
  2. Генерация кодов TOTP двухфакторной аутентификации
  3. Сохранение и восстановление ваших настроек конфигурации
  4. Предоставление функциональности эмуляции терминала
  5. Предоставление функциональности передачи файлов SFTP
  6. Импорт/экспорт конфигурации через QR-коды (выполняется только локально на вашем устройстве, без участия серверов)

Мы не будем использовать вашу информацию для иных целей.

3. Хранение и безопасность информации

  • Локальное хранение: Все данные хранятся локально на вашем устройстве и защищены механизмом песочницы приложения.
  • Шифрование данных: Конфиденциальные данные (например, пароли SSH) шифруются с использованием AES-256-CBC.
  • Аппаратная защита закрытых ключей: SSH закрытые ключи шифруются и хранятся в защищённом оборудовании устройства (Android Keystore / iOS Keychain), расшифровываются в память только при установке соединения, без сохранения открытого текста на диске.
  • Защита секрета TOTP: Секреты TOTP хранятся как часть конфигурации подключения на локальном устройстве и защищены песочницей приложения.
  • Блокировка приложения: Это Приложение поддерживает биометрическую (отпечаток/распознавание лица) или блокировку по учётным данным устройства для предотвращения несанкционированного доступа (необходимо включить вручную).
  • Без загрузки в сеть: Мы не загружаем ваши данные на какой-либо сервер. SSH-соединения устанавливаются напрямую между вашим устройством и целевым сервером.

4. Передача информации

Мы не передаём вашу личную информацию третьим лицам, за исключением случаев, когда:

  1. Вы дали явное согласие
  2. Это требуется законодательством и нормативными актами
  3. Это требуется государственными органами в соответствии с законом

5. Экспорт и удаление данных

  • Вы можете в любой момент создать резервную копию данных конфигурации с помощью функции экспорта приложения (экспортированные файлы сохраняются только на вашем устройстве).
  • Вы можете в любой момент удалить хосты, ключи и другие данные.
  • Удаление этого Приложения приведёт к удалению всех локальных данных.
  • Функции импорта/экспорта QR-кодов обрабатывают данные только на вашем устройстве, без промежуточных серверов.

6. Сетевое подключение

  • Это Приложение подключается к указанным вами удалённым серверам по протоколу SSH. Данные подключения передаются напрямую между вашим устройством и целевым сервером.
  • Это Приложение не ретранслирует данные SSH-соединения через промежуточные серверы.
  • Соединения Mosh используют протокол UDP для прямого подключения к целевому серверу.
  • Безопасность всех SSH / Mosh-соединений обеспечивается встроенным механизмом шифрования протокола SSH.

7. Разрешения

  • Сеть: Для установки SSH / Mosh-соединений. Целевые серверы указываются вами.
  • Уведомления: Для службы переднего плана, поддерживающей стабильные SSH-соединения (только Android). Уведомления отображают только статус соединения.
  • Биометрия: Для функции блокировки приложения (необходимо включить вручную). Биометрические данные обрабатываются системной службой безопасности; это Приложение не имеет доступа к биометрическим данным, не хранит и не загружает их.
  • Камера: Для сканирования QR-кодов при импорте конфигурации (необходимо инициировать вручную). Изображения камеры обрабатываются только локально на вашем устройстве; никакие изображения не загружаются и не сохраняются.
  • Хранилище: Для импорта/экспорта файлов конфигурации и передачи файлов SFTP (доступ только к указанным вами файлам).

8. Защита несовершеннолетних

Мы уделяем большое внимание защите личной информации несовершеннолетних. Если вы не достигли 14-летнего возраста, используйте это Приложение под руководством опекуна.

Мы можем время от времени обновлять настоящую Политику конфиденциальности. При внесении изменений мы уведомим вас в приложении и попросим согласиться повторно. Если вы не согласны с обновлённой Политикой конфиденциальности, вы можете прекратить использование этого Приложения.
