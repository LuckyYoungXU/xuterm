XuTerm 隐私政策

SSH 终端客户端 · 您的隐私由您自己掌握

English Version

更新日期：2026年6月20日

XuTerm（以下简称「本应用」）非常重视用户隐私保护。本隐私政策旨在向您说明我们如何收集、使用、存储和保护您的个人信息。

核心承诺：本应用不会收集、上传或与任何第三方共享您的任何个人信息。所有数据仅存储在您的本地设备上。

一、我们收集的信息

本应用是一款 SSH 终端客户端工具，所有数据均存储在您的本地设备上，我们不会主动收集、上传或分享您的任何个人信息。

1. 您主动提供的信息

  • SSH 连接信息：主机地址、端口、用户名、密码/密钥（仅用于建立 SSH 连接，存储在本地设备）
  • 快捷命令配置：您自定义的快捷命令（仅存储在本地设备）
  • 端口转发规则：您配置的端口转发规则（仅存储在本地设备）
  • 终端设置：字体、主题、快捷键等偏好设置（仅存储在本地设备）

2. 自动收集的信息

  • 本应用不自动收集任何设备信息、位置信息或使用行为数据。
  • 本应用不包含任何第三方统计分析 SDK。
  • 本应用不使用任何广告 SDK 或追踪工具。

二、信息的使用

您的信息仅用于以下目的：

  1. 建立和管理 SSH / Mosh 连接
  2. 保存和恢复您的配置偏好
  3. 提供终端模拟功能
  4. 提供 SFTP 文件传输功能
  5. 实现配置的二维码导入/导出（仅在设备本地执行，不经过任何服务器）

我们不会将您的信息用于除此以外的任何目的。

三、信息的存储与安全

  • 本地存储：所有数据均存储在您的本地设备上，使用应用沙盒存储机制保护。
  • 数据加密：敏感数据（如 SSH 密码）通过 AES-256-CBC 加密存储。
  • 应用锁：本应用支持生物识别（指纹/人脸）或设备凭证锁功能，可防止未授权访问（需您主动开启）。
  • 不联网上传：我们不会将您的数据上传至任何服务器。SSH 连接直接在您的设备与目标服务器之间建立。

四、信息的共享

我们不会与任何第三方共享您的个人信息，除非：

  1. 获得您的明确同意
  2. 法律法规要求
  3. 政府主管部门依法要求

五、数据的导出与删除

  • 您可以随时通过应用的导出功能备份您的配置数据（导出的文件仅保存在您的设备上）。
  • 您可以随时删除您的主机、密钥等数据。
  • 卸载本应用将清除所有本地数据。
  • 二维码导入/导出功能生成的数据仅在您的设备内部处理，不经过任何中间服务器。

六、网络连接说明

  • 本应用通过 SSH 协议连接到您指定的远程服务器，连接数据直接在您的设备与目标服务器之间传输。
  • 本应用不通过任何中间服务器转发您的 SSH 连接数据。
  • Mosh 连接使用 UDP 协议直连目标服务器。
  • 所有 SSH / Mosh 连接的安全由 SSH 协议本身的加密机制保障。

七、权限使用说明

  • 网络权限：用于建立 SSH / Mosh 连接。连接的目标服务器由您自行指定。
  • 通知权限：用于前台服务保持 SSH 连接稳定（仅 Android）。通知内容仅显示连接状态。
  • 生物识别权限：用于应用锁功能（需您主动开启）。生物识别数据由系统安全服务处理，本应用不访问、存储或上传任何生物识别数据。
  • 相机权限：用于扫描二维码导入配置（需您主动发起）。相机画面仅在您的设备本地处理，不会上传或保存任何图像。
  • 存储权限：用于导入/导出配置文件和 SFTP 文件传输（仅访问您指定的文件）。

八、未成年人保护

我们高度重视对未成年人个人信息的保护。若您是未满 14 周岁的未成年人，请在监护人指导下使用本应用。

九、隐私政策的变更

我们可能会适时修订本隐私政策。政策变更后，我们会在应用内通知您并要求您重新同意。若您不同意变更后的隐私政策，您可以选择停止使用本应用。
