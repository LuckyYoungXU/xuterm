1. 快速入门

1.1 安装应用

XuTerm 支持多个下载渠道，选择适合你的方式安装：

  • 华为应用市场 — 华为设备专用，搜索"XuTerm"即可找到。
  • APKPure — 适用于所有 Android 设备，下载 APK 直接安装。
  • Appteka.store — 第三方 Android 应用商店。
  • App Store — iOS 版本即将上线，敬请期待。
  • Google Play — 即将上线。

1.2 建立第一个 SSH 连接

  1. 打开 XuTerm，首次启动将进入主机管理界面。
  2. 点击右上角的 + 按钮添加新主机。
  3. 填写必要信息：
    • 名称 — 给连接起一个好记的名字（例如"生产环境 Web 服务器"）。
    • 主机 — 服务器 IP 地址或域名。
    • 端口 — SSH 端口（默认：22）。
    • 用户名 — 服务器登录用户名。
  4. 选择认证方式：
    • 密码认证 — 输入密码，保存后将加密存储。
    • 密钥认证 — 选择已添加的 SSH 密钥对（详见 SSH 密钥管理）。
  5. 点击 保存，然后点击主机卡片即可连接。
  6. 首次连接时，Android 可能会请求通知权限 — 这是用于后台保活服务，防止系统杀死连接。
如果你的服务器在堡垒机后面，请参阅 代理跳转 配置多跳连接。

2. 主机管理

2.1 添加主机

在主机管理界面点击 + 按钮，主机配置表单包含以下字段：

  • 名称（必填）— 主机显示名称。
  • 主机（必填）— IP 地址或域名。
  • 端口 — 默认 22。
  • 用户名（必填）— SSH 登录用户名。
  • 密码 — 保存后使用 AES-256 加密存储。
  • SSH 密钥 — 选择密钥对进行密钥认证。
  • 分组 — 将主机分配到分组中以便管理。
  • 描述 — 关于该主机的备注信息。
  • 使用 Mosh — 切换为 Mosh 协议连接（详见 Mosh）。
  • 使用 tmux — 连接时自动附加或创建 tmux 会话（详见 tmux）。
  • 自动重连 — 连接断开时自动重连，可配置间隔时间（默认 30 秒）。
  • Agent 转发 — 启用 SSH Agent 转发。
  • 跳板机 — 选择代理主机用于堡垒机/跳板机连接（详见 代理跳转）。
  • TOTP 令牌 — 关联 TOTP 令牌，实现一键填充两步验证码（详见 TOTP）。
  • 启用服务器监控 — 开启该主机的实时资源监控。
  • trzsz 下载路径 — 设置 trzsz 文件下载的本地目录。

2.2 编辑与复制主机

长按主机卡片打开上下文菜单，提供以下操作：

  • 编辑 — 修改主机配置。
  • 复制 — 复制该主机并自动生成新名称（适合快速创建相似配置）。
  • 分享 — 生成该主机的二维码（详见 二维码分享）。
  • 断开连接 — 关闭该主机的活跃 SSH 连接。
  • 删除 — 移除该主机（需确认）。

2.3 分组与排序

使用彩色分组来组织你的主机：

  • 点击工具栏的 分组+ 按钮（+ 旁边）创建新分组，可自定义名称和颜色。
  • 在顶部的水平标签栏中选择分组，按分组筛选主机。
  • 拖拽排序：长按分组标签并拖动可调整分组顺序。长按但不拖动可弹出编辑/删除选项。
  • 在分组视图下，长按并拖拽主机卡片可在分组内重新排序。
  • 在"全部"视图下，主机按分组标题分组显示，可在各自分组内拖拽排序。
  • 包含主机的分组无法删除 — 需先移动或删除组内主机。
使用工具栏中的 视图切换 按钮可在紧凑模式和普通模式之间切换。在平板设备上，主机以网格布局展示。

2.4 二维码分享

通过二维码即时分享主机配置：

  1. 长按主机卡片选择 分享，或使用批量分享（见下方）。
  2. 系统生成包含主机连接信息的二维码。
  3. 另一台设备扫描二维码即可导入该主机配置。
出于安全考虑，二维码中不包含密码信息。导入后需要手动输入密码。

2.5 二维码扫描导入

点击工具栏的 扫描 按钮，扫描 XuTerm 二维码即可将主机配置导入到你的主机列表中。

2.6 批量操作

点击工具栏的 多选 按钮进入多选模式：

  • 点击主机卡片来选择/取消选择。
  • 使用 全选 快速选中当前分组的所有主机。
  • 点击 分享 为所有选中的主机生成一个二维码。
  • 点击 取消 或返回按钮退出多选模式。

3. 终端操作

3.1 基础终端操作

连接到主机后进入终端界面。顶部栏显示连接状态和主机名称。主要交互方式：

  • 输入命令 — 使用屏幕键盘或外接键盘输入。
  • 滚动 — 上下滑动浏览终端输出历史。
  • 返回按钮 — 返回主机列表，连接在后台保持活跃。
  • 连接指示器 — 显示连接状态：已连接（绿色）、重连中（黄色）、已断开（红色）。

3.2 终端搜索

在终端输出中搜索内容，快速定位关键信息：

  1. 点击终端工具栏中的 搜索图标 打开搜索栏。
  2. 输入搜索关键词 — 所有匹配结果实时高亮显示。
  3. 使用 上/下箭头 在匹配项之间导航，终端自动滚动到当前匹配位置。
  4. 匹配计数器（如"3/15"）显示当前匹配位置和总数。
  5. 点击 关闭 或返回按钮退出搜索模式。

3.3 手势缩放

在终端上使用双指缩放手势调整字体大小：

  • 双指向外捏合 — 放大字体。
  • 双指向内捏合 — 缩小字体。
  • 字体大小平滑变化，即时生效。你的偏好大小会被记住。
也可以在 设置 > 终端字体 中设置默认字体大小。

3.4 选择与复制

从终端输出中复制文本：

  1. 在终端上 长按 进入选择模式。
  2. 拖拽选择手柄来扩展选择范围。
  3. 选中的文本自动复制到剪贴板。
  4. 粘贴：长按终端输入区域选择"粘贴"，或使用快捷键栏的粘贴按钮。

3.5 快捷键栏

键盘上方的快捷键栏提供常用特殊按键和操作的快速访问：

  • Tab、Ctrl、Alt、Esc — 终端命令修饰键。
  • 方向键 — 上、下、左、右导航。
  • Home / End — 跳转到行首或行尾。
  • Page Up / Page Down — 按页滚动。
  • 功能键 — F1 到 F12。
  • 点击 Ctrl 或 Alt 可激活为粘滞修饰键 — 下一次按键将以该修饰键组合发送。
你可以在 设置 > 终端 > 快捷键 中自定义快捷键栏显示哪些按键。

3.6 快捷命令

保存常用命令，一键执行：

  1. 在终端中，点击工具栏的 快捷命令 按钮（火箭图标）。
  2. 浏览按分类组织的已保存命令。
  3. 点击命令即可直接发送到终端。
  4. 管理命令请进入快捷命令管理界面（设置 > 终端 > 快捷命令）。

快捷命令管理功能：

  • 添加 — 创建新命令，包含名称、内容和分类。
  • 编辑 / 删除 — 长按命令查看操作选项。
  • 排序 — 拖拽命令调整顺序。
  • 二维码导入/导出 — 通过二维码分享和导入快捷命令。

3.7 命令片段

命令片段是可复用的多行脚本模板，比快捷命令更加强大：

  1. 在终端中，点击工具栏的 片段 按钮。
  2. 按分组浏览命令片段。
  3. 点击片段将其内容粘贴到终端输入中。

片段管理（设置 > 终端 > 命令片段）：

  • 添加 — 创建包含名称、内容和分组的片段。
  • 拖拽排序 — 在分组内重新排列片段。
  • 编辑 / 删除 — 长按查看操作选项。
  • 支持自定义分组进行组织。

3.8 命令历史

快速重复执行之前运行过的命令：

  1. 点击终端工具栏的 历史 按钮（时钟图标）。
  2. 浏览当前会话的已执行命令列表。
  3. 点击命令即可再次发送到终端。

3.9 sudo 密码自动填充

如果你为主机存储了 sudo 密码，XuTerm 会自动检测 sudo 提示：

  1. 当终端显示 sudo 密码提示时，会自动出现填充按钮。
  2. 点击按钮即可自动填入 sudo 密码。
要存储 sudo 密码，需在主机配置中启用该选项并在提示时输入密码。密码使用 AES-256 加密存储。

3.10 TOTP 两步验证码填充

当主机关联了 TOTP 令牌时，XuTerm 可自动生成并填充两步验证码：

  1. 当终端显示两步验证提示时，会自动出现填充按钮。
  2. 点击按钮即可生成并插入当前 TOTP 验证码。

设置方法详见 TOTP 两步验证。

4. Mosh — 移动 Shell

Mosh（Mobile Shell）是 SSH 的替代协议，能优雅应对间歇性连接、网络漫游和高延迟环境，提供即时响应和自动重连。

4.1 启用 Mosh

  1. 编辑主机配置（见 编辑主机）。
  2. 将 使用 Mosh 开关打开。
  3. 保存主机。下次连接将使用 Mosh 协议。
远程服务器需要安装 mosh-server。Mosh 先通过 SSH 建立连接，然后切换到 Mosh 协议（UDP）。请确保服务器防火墙允许 Mosh 端口范围（默认 60000-61000）的 UDP 流量。

4.2 Mosh 配置

  • Mosh 端口 — 指定 Mosh 连接使用的 UDP 端口。留空则自动选择。
  • Mosh 服务器路径 — 如果 mosh-server 安装在非标准路径，在此指定完整路径。

通过 Mosh 连接时，终端顶栏会显示"Mosh"标识，表明当前使用的是 Mosh 协议。

5. tmux 集成

XuTerm 提供与 tmux 的深度集成，让多路复用器会话在手机上也有原生体验。

5.1 启用 tmux

  1. 编辑主机配置。
  2. 将 使用 tmux 开关打开。
  3. 可选择指定 tmux 会话名称。留空则 XuTerm 自动创建新会话或附加到最近的会话。
  4. 保存并连接。XuTerm 会在连接后自动执行 tmux attach 或 tmux new-session。
远程服务器需要安装 tmux。XuTerm 会自动检测 tmux 版本并适配集成方式。

5.2 tmux 操作栏

当 tmux 会话处于活跃状态时，终端底部会出现专用的操作栏：

  • 窗口标签 — 每个 tmux 窗口的可视化标签页，点击即可快速切换。
  • 新建窗口 — 创建新的 tmux 窗口。
  • 关闭窗口 — 关闭当前 tmux 窗口。
  • 重命名窗口 — 为当前窗口重新命名。
  • 分割窗格 — 水平或垂直分割当前窗格。
  • 切换窗格 — 在分割的窗格之间切换焦点。
  • 分离 — 从 tmux 会话分离（会话在服务器端继续运行）。

5.3 tmux 主题

XuTerm 为 tmux 应用了一个针对移动端优化的自定义主题。状态栏样式与应用主题匹配，与终端显示无缝集成。启用 tmux 后自动应用。

6. SFTP 文件浏览器

XuTerm 内置 SFTP 文件浏览器，可直接管理远程服务器上的文件。

6.1 浏览文件

  1. 连接主机后，点击终端工具栏的 SFTP 按钮打开文件浏览器。
  2. 浏览器默认打开 SSH 会话的工作目录（或主目录）。
  3. 点击目录进入，点击 .. 或使用路径栏返回上级。
  4. 顶部路径栏显示当前目录 — 点击任意层级可快速跳转。
  5. 点击 主页图标 跳转到主目录。
  6. 使用 排序按钮 按名称、大小或修改时间排序文件。
  7. 使用工具栏的 眼睛图标 切换是否显示隐藏文件（以点开头的文件）。
  8. 使用 搜索图标 在当前目录中按文件名筛选。

6.2 上传与下载

上传（本地到远程）：

  1. 点击 SFTP 工具栏的 上传 按钮。
  2. 通过文件选择器从设备中选择文件。
  3. 文件将上传到当前远程目录。
  4. 进度条实时显示传输状态。

下载（远程到本地）：

  1. 长按文件或目录选中，然后点击 下载。
  2. 也可以先点击文件预览，再使用下载选项。
  3. 下载的文件保存到设备的下载目录（或自定义的 trzsz 下载路径）。
通过蜂窝网络传输文件时，XuTerm 会发出警告并请求确认（详见 蜂窝网络传输）。

6.3 文件操作

长按文件或目录打开上下文菜单：

  • 打开 / 预览 — 使用内置查看器或外部应用打开文件。
  • 编辑 — 在内置代码编辑器中打开（详见 文件预览与编辑）。
  • 重命名 — 修改文件或目录名称。
  • 删除 — 删除文件或目录（需确认）。
  • 权限 — 查看和修改文件权限（chmod）。
  • 下载 — 下载到本地设备。
  • 复制路径 — 复制完整文件路径到剪贴板。
  • 哈希 — 计算文件的 MD5、SHA1 或 SHA256 校验和。

工具栏还提供以下操作：

  • 新建文件 — 在当前目录创建空文件。
  • 新建目录 — 创建新文件夹。

6.4 文件预览与编辑

XuTerm 可以直接预览和编辑多种文件类型：

  • 文本/代码文件 — 在内置代码编辑器中打开，支持多种语言的语法高亮（Python、JavaScript、Go、Rust、YAML、JSON 等）。编辑器支持查找/替换、行号显示，以及直接保存回远程服务器。
  • PDF 文件 — 使用内置 PDF 查看器查看，支持缩放和翻页。
  • Excel / CSV 文件 — 以表格形式预览电子表格数据。
  • 图片 — 查看图片（PNG、JPG、GIF、BMP、WebP、SVG），支持双指缩放。
  • Markdown — 渲染预览 Markdown 文件，显示正确的格式。
在代码编辑器中，使用 查找 功能在文件内搜索。匹配结果高亮显示，可使用上一个/下一个按钮导航。编辑器会自动检测文件语言以进行语法高亮。

6.5 蜂窝网络传输

默认情况下，XuTerm 在通过蜂窝网络（移动数据）传输文件前会发出警告：

  1. 在蜂窝网络下发起文件传输时，会弹出确认对话框。
  2. 你可以选择继续或取消。
  3. 要始终允许蜂窝网络传输，请在 设置 > 连接 中启用 允许蜂窝网络传输。

6.6 文件哈希校验

通过计算校验和验证文件完整性：

  1. 长按文件选择 哈希。
  2. 选择算法：MD5、SHA1 或 SHA256。
  3. 显示哈希值并可复制到剪贴板。

7. trzsz 文件传输

trzsz 提供类似 lrzsz（rz/sz）的终端文件传输体验，但兼容 tmux 并提供更好的进度显示。

  1. 确保远程服务器已安装 trzsz（Python 包 trzsz 或 trzsz-go）。
  2. 上传：在终端输入 trz，XuTerm 弹出文件选择器。选择文件并确认。
  3. 下载：在终端输入 tsz <文件名>，文件将下载到你的设备。
  4. 传输过程中显示实时进度条，包含文件名、百分比和传输速度。
trzsz 在 tmux 会话中无缝工作，不受传统 rz/sz 在 tmux 下会失效的限制。

你可以在 设置 > 连接 中配置默认下载目录，或通过主机的 trzsz 下载路径 字段单独配置。

8. 端口转发

XuTerm 支持三种 SSH 端口转发模式。

8.1 本地端口转发（-L）

通过 SSH 隧道将本地端口转发到远程地址，这是最常用的类型。

示例：访问只监听 localhost 的远程数据库：

  • 绑定地址：127.0.0.1
  • 绑定端口：3306（你设备上的本地端口）
  • 目标地址：127.0.0.1（从远程服务器视角）
  • 目标端口：3306（远程服务的端口）

启用后，在你的设备上连接 127.0.0.1:3306 即可访问远程数据库。

8.2 远程端口转发（-R）

将远程服务器上的端口转发到本地地址。适用于将本地服务暴露到远程网络。

8.3 动态（SOCKS）转发（-D）

创建 SOCKS 代理，通过 SSH 连接隧道传输流量。指定本地绑定地址和端口，然后将你的应用配置为使用该 SOCKS5 代理。

8.4 连接时自动启动

端口转发规则可配置为连接主机时自动启动：

  1. 在端口转发管理界面创建规则（可从终端工具栏或设置中访问）。
  2. 切换每条规则的 启用 开关来控制是否自动启动。
  3. 连接时，所有启用的规则将自动建立。
你可以随时启用/禁用端口转发规则而无需重新连接 — 只需切换开关即可。

9. 代理跳转（堡垒机）

通过中间堡垒机/跳板机连接到目标服务器：

  1. 首先，将 堡垒机 作为普通主机添加到 XuTerm 中。
  2. 编辑 目标主机 的配置。
  3. 在 跳板机 字段中，选择你添加的堡垒机。
  4. 保存并连接。XuTerm 先建立到堡垒机的 SSH 连接，然后通过隧道连接到目标服务器。
支持多跳代理链。主机 A 可通过主机 B 跳转，而主机 B 本身又可通过主机 C 跳转，以此类推。

10. SSH 密钥管理

10.1 生成密钥

  1. 进入 SSH 密钥 管理界面（可从设置或主机表单中访问）。
  2. 点击 添加 并选择 生成新密钥。
  3. 选择密钥类型：
    • RSA — 兼容性最广，2048/3072/4096 位。
    • ECDSA — 现代、高效，256/384/521 位。
    • Ed25519 — 推荐用于新部署，安全性最强且密钥最小。
  4. 可选择为私钥设置密码短语。
  5. 点击 生成。密钥对创建后安全存储在设备上。
  6. 你可以复制 公钥 添加到服务器的 ~/.ssh/authorized_keys 中。

10.2 导入密钥

  1. 点击 添加 并选择 导入密钥。
  2. 粘贴私钥内容或从设备选择密钥文件。
  3. 如果密钥已加密，需提供密码短语。
  4. 密钥导入后使用 AES-256 加密存储。

10.3 将密钥分配给主机

  1. 编辑主机配置。
  2. 在 SSH 密钥 下拉菜单中，选择要使用的密钥对。
  3. 如果只想使用密钥认证，请清空密码字段。
  4. 保存并连接。
SSH 密钥管理界面显示每个密钥的指纹和使用该密钥的主机数量。删除未使用的密钥以保持列表整洁。

11. TOTP 两步验证

11.1 添加 TOTP 令牌

  1. 进入 TOTP 令牌 管理界面。
  2. 点击 添加 创建新令牌。
  3. 输入令牌详情：
    • 名称 — 令牌标签（如"GitHub 2FA"）。
    • 密钥 — 来自服务的 base32 编码密钥。
    • 分组 — 将令牌组织到分组中。
  4. 也可以 扫描二维码 自动填充密钥。
  5. 保存令牌。将显示当前验证码和倒计时。

令牌管理功能：

  • 编辑 / 删除 — 修改或移除令牌。
  • 分组 — 使用自定义分组和颜色组织令牌。
  • 二维码分享 — 通过二维码分享令牌配置（密钥已加密）。

11.2 在终端中使用 TOTP

  1. 在主机配置的 TOTP 令牌 字段中关联一个 TOTP 令牌。
  2. 当终端显示两步验证提示时，会自动出现填充按钮。
  3. 点击按钮即可生成并自动填入当前 6 位验证码。

12. 服务器监控

在 SSH 会话中实时监控服务器资源。

  1. 在主机配置中启用 服务器监控。
  2. 连接后，终端顶部出现监控栏，显示：
    • CPU 使用率 — 实时百分比及迷你走势图。
    • 内存使用 — 已用/总量及百分比。
    • 磁盘使用 — 已用/总量及百分比。
    • 负载均值 — 1分钟、5分钟、15分钟。
  3. 点击监控栏打开详细监控视图，包含：
    • CPU、内存、磁盘和负载详情及可视化图表。
    • 进程列表 — 按 CPU 或内存使用排序查看运行中的进程。
    • 杀死进程 — 选择进程并发送 kill 信号。

在 设置 > 服务器监控 中配置刷新间隔：

  • 监控栏间隔 — 顶部摘要刷新频率（3-60 秒，默认 5 秒）。
  • 详情间隔 — 详细视图刷新频率（1-30 秒，默认 3 秒）。

13. 可视化运维面板

可视化运维面板将常用服务器运维操作以图形化界面呈现，点击即达，无需记忆和输入命令。所有操作通过 SSH 通道在后台执行，与终端共用同一连接。

13.1 进入面板

  • 在主机列表中，点击主机卡片右侧的 可视化运维按钮（心率图标）即可进入。
  • 无需先建立终端连接 — 面板会自动复用已有的 SSH 连接，或在需要时自动建立新连接。
  • 面板顶部显示主机名与连接状态，并提供 终端 按钮（跳转到该主机的终端）和 刷新 按钮。
部分操作（如服务启停、防火墙开关、终止进程）需要远程用户具备 sudo 权限。若主机存储了 sudo 密码，将自动使用。

13.2 系统摘要

面板首页以卡片形式一屏总览服务器关键信息：

  • 系统信息 — 操作系统、主机名、内网 IP、开机时间。
  • CPU — 核心数与实时使用率。
  • 内存 — 已用/总量及百分比。
  • 磁盘 — 已用/总量及百分比。
  • 负载 — 1/5/15 分钟负载均值。
  • 网络 — 实时网络速率。

点击 刷新 可随时更新数据。

13.3 磁盘分析

查看磁盘分区占用并逐层定位大文件：

  1. 磁盘分析页列出所有分区，显示使用率、文件系统类型、已用/可用空间。
  2. 点击任一分区卡片，进入该挂载点的目录空间分析。
  3. 分析结果按占用大小排序列出各子目录与文件。
  4. 使用顶部 面包屑导航，点击任意路径片段可切换到该层目录重新分析。
  5. 分析过程中可随时 取消 当前分析。
  6. 上次分析的目录会被记住，下次进入时直接恢复。

13.4 systemd 服务管理

以图形方式管理 systemd 服务：

  • 服务列表 — 显示每个服务的名称、运行状态与描述。
  • 搜索 — 按名称快速过滤服务。
  • 状态过滤 — 按 running / stopped / failed 筛选服务。
  • 服务详情 — 点击服务查看详情，可执行：
    • 启动（start） — 启动已停止的服务。
    • 重启（restart） — 重启服务（需二次确认）。
    • 停止（stop） — 停止服务（需二次确认）。
    • 状态输出 — 查看并复制 systemctl status 的完整输出。

13.5 进程管理

查看和管理服务器上运行的进程：

  • 进程列表 — 显示 PID、用户、CPU、内存、命令等信息。
  • 搜索 — 按名称或 PID 过滤进程。
  • 排序 — 按 CPU 或内存使用率排序。
  • 进程详情 — 点击进程查看详情，可发送信号：
    • TERM — 请求进程正常退出。
    • KILL — 强制终止进程（需二次确认）。

13.6 网络工具

网络状态查看与连通性诊断：

  • 网络接口 — 接口名称、状态与 IP 地址，点击 IP 可复制。
  • 监听端口 — 协议、监听地址及占用端口的进程。
  • 活动连接 — 当前已建立的网络连接。
  • Ping 诊断 — 输入主机名或 IP 执行 ping 测试，查看延迟与丢包。查询自动记入历史（见 查询历史）。

13.7 Docker 容器管理

在手机上完成容器日常运维：

  • 容器列表 — 显示运行状态、所用镜像、端口映射，点击容器打开详情。
  • 容器操作 — 详情页支持：
    • 启动 / 停止 / 重启 容器。
    • 查看日志 — 查看容器运行日志。
    • 删除 — 移除容器（需二次确认）。
  • 镜像列表 — 查看服务器上的 Docker 镜像。
远程服务器需安装 Docker，且当前用户可访问 Docker（通常需加入 docker 组或具备 sudo 权限）。

13.8 防火墙管理

图形化管理服务器防火墙，支持 ufw 和 firewalld 两种后端（自动检测）：

  • 状态总览 — 显示防火墙后端与启用状态，一键开关。
  • 规则列表 — 查看已放行的端口/服务规则。
  • 添加规则 — 输入端口、协议（TCP/UDP）即可放行。
  • 删除规则 — 移除不再需要的规则（需二次确认）。
启用防火墙时，XuTerm 会检测当前 SSH 端口是否已放行，防止规则生效后将你锁在服务器之外。请谨慎操作远程防火墙。

13.9 crontab 定时任务

以可视化方式管理当前用户的 crontab：

  • 任务列表 — 每条任务以人话描述展示（如"每天 03:00 执行备份"），并估算下次运行时间。
  • 添加任务 — 通过模板编辑器创建定时任务，无需记忆 cron 表达式语法。
  • 编辑 / 删除 — 修改或移除已有任务。
  • 启用 / 停用 — 一键注释或取消注释任务，临时停用而不删除。
面板中还包含 SFTP 文件管理模块，功能与 SFTP 文件浏览器相同。

14. 工具箱

工具箱提供 16 种内置运维小工具，全部在本地运行、无需连接服务器。通过底部导航栏的 工具箱 页签进入，支持列表/网格两种视图切换。

14.1 安全工具

  • RSA 密钥生成 — 生成 SSH 密钥对（支持 RSA 和 Ed25519），可设置密钥名称与密码短语。生成后可复制私钥 PEM、公钥字符串和指纹，直接用于主机配置。
  • 密码生成 — 可配置长度、大小写字母、数字、特殊字符，并过滤易混淆字符（0/O、1/l 等），一键生成随机强密码并复制。
  • JWT 工具 — 粘贴 JWT 即可解码查看 header 与 payload；输入密钥可验证签名；也可使用 HS256 密钥生成新 token。

14.2 网络工具

  • DNS 解析 — 输入域名查询解析记录。
  • Whois — 查询域名注册信息（注册商、到期时间、DNS 服务器等）。
  • SSL 证书查询 — 查看目标站点的证书详情（颁发者、有效期、SAN 等）。
  • TCP 端口测试 — 输入主机与端口，检测 open / closed / timeout 状态及连接耗时。
  • CIDR 计算 — 输入 IP/前缀，计算网络地址、广播地址、子网掩码、通配符掩码、可用主机范围，并标注 IP 类别与是否私有地址。

14.3 编码与开发工具

  • Base64 编解码 — 支持标准 Base64、URL 安全、Hex、Unicode 等模式的编码与解码。
  • JSON 格式化 — 粘贴 JSON 自动格式化或压缩，容错修复常见格式问题，并精确定位错误位置。
  • 正则测试 — 输入正则表达式与测试文本，实时查看匹配高亮并测试替换结果。
  • 时间戳转换 — Unix 时间戳与日期时间互转。
  • 进制转换 — 二进制/八进制/十进制/十六进制互转，支持大数（BigInt）。
  • URL 解析 — 拆解 URL 的协议、主机、端口、路径、查询参数、片段等组成部分。
  • ASCII 表 — 随时查阅 ASCII 字符对照表。
  • 二维码 — 通过相机扫描或导入图片解码二维码内容。

14.4 查询历史

DNS、Whois、SSL、Ping 等查询工具会自动记录查询历史：相同查询自动去重并置顶，点击历史条目即可快速重新执行，免去重复输入。

15. 会话快照

保存和恢复终端会话状态，快速恢复工作环境：

  1. 连接状态下，点击终端工具栏的 快照 按钮。
  2. 保存当前会话的快照，包含：
    • 主机连接详情。
    • 终端回滚缓冲区（可见输出）。
    • 时间戳。
  3. 从会话快照管理界面查看已保存的快照。
  4. 点击快照可恢复会话状态并重新连接到主机。
  5. 删除不再需要的快照。

16. 多会话管理

XuTerm 支持同时连接多台服务器：

  • 多主机连接 — 每个连接打开一个新的终端标签页。
  • 切换会话 — 使用终端顶部的标签栏在活跃连接之间切换。
  • 后台会话 — 导航离开时连接在后台保持活跃。主机列表显示活跃连接的徽章计数器。
  • 重新进入会话 — 在主机列表中点击已连接的主机返回其终端。
在 Android 上，前台服务通知可保持你的连接在应用后台时仍然活跃。

17. 应用设置

17.1 生物识别锁

使用生物识别保护 XuTerm：

  1. 进入设置，打开 生物识别解锁 开关。
  2. 应用将使用你设备的生物识别硬件（面容 ID、触控 ID 或指纹）。
  3. 启用后，每次打开应用都需要进行身份验证。

17.2 终端设置

通过 设置 > 终端 访问，可配置：

  • 快捷命令 — 管理已保存的快捷命令。
  • 命令片段 — 管理命令片段分组和条目。
  • 快捷键 — 自定义快捷键栏中显示的按键。可启用/禁用单个按键，添加自定义按键绑定。
  • tmux — 配置 tmux 集成行为。

17.3 字体设置

通过 设置 > 终端字体 访问，可配置：

  • 字体大小 — 默认终端字体大小（8-28 可调）。
  • 行高 — 终端行间距（1.0x 到 2.0x）。
  • 字体族 — 从内置等宽字体中选择：
    • Source Code Pro
    • JetBrains Mono
    • Fira Code
    • Cascadia Code

17.4 竖向色条

竖向色条是终端左侧的彩色竖条，从视觉上区分用户输入和服务端输出：

  • 进入 设置 > 竖向色条 进行配置。
  • 启用/禁用 — 开关色条。
  • 输入颜色 — 你输入的命令行的颜色。
  • 输出颜色 — 服务器响应行的颜色。
色条在滚动查看长日志时特别有用 — 帮助你快速找到输入命令的位置和输出的起始位置。

17.5 连接设置

通过 设置 > 连接 访问，可配置：

  • 端口转发自动启动 — 连接时是否自动建立端口转发规则。
  • SFTP 显示隐藏文件 — SFTP 浏览器中隐藏文件的默认可见性。
  • 允许蜂窝网络传输 — 传输文件时跳过蜂窝网络警告。
  • trzsz 设置 — 配置 trzsz 的默认上传/下载目录。

17.6 监控设置

配置服务器监控的刷新间隔（详见 服务器监控）。

17.7 主题与外观

进入设置后可配置：

  • 主题模式 — 从以下选项选择：
    • 浅色模式
    • 深色模式
    • 跟随系统
  • 屏幕方向锁定 — 锁定屏幕方向防止旋转。

17.8 语言

XuTerm 支持多种语言：

  • 简体中文
  • 繁体中文
  • English
  • 日本語
  • Русский
  • 跟随系统

进入 设置 > 语言 可更改显示语言，更改立即生效。

18. 数据管理

18.1 导出配置

将你的 XuTerm 配置备份到文件：

  1. 进入 设置 > 数据管理 > 导出。
  2. 选择要导出的数据：
    • 主机
    • SSH 密钥
    • 快捷命令
    • 命令片段
    • 端口转发规则
    • TOTP 令牌
  3. 可选择使用密码 加密 导出文件以增强安全性。
  4. 点击 导出 将配置文件保存到你的设备。

18.2 导入配置

恢复之前导出的配置：

  1. 进入 设置 > 数据管理 > 导入。
  2. 从设备中选择配置文件。
  3. 如果文件已加密，输入密码进行解密。
  4. 查看内容并确认导入。
  5. 导入的数据与现有数据合并 — 重复项将智能处理。

18.3 iCloud 同步（iOS）

在 iOS 设备上，XuTerm 支持 iCloud 同步，在所有 Apple 设备间保持配置一致：

  1. 进入 设置 > 数据管理 > iCloud 同步。
  2. 启用 iCloud 同步，你的配置将自动上传到 iCloud。
  3. 在另一台使用相同 Apple ID 的 iOS 设备上，启用 iCloud 同步即可下载配置。
  4. 变更会双向同步。

19. 安全与隐私

XuTerm 以安全和隐私为最高优先级进行设计：

  • AES-256 加密 — 所有敏感数据（密码、SSH 密钥、TOTP 密钥）在存储前均使用 AES-256 加密。
  • 安全密钥存储 — SSH 私钥和密码存储在设备的安全硬件中（iOS Keychain / Android Keystore）。
  • 生物识别保护 — 可选的面容 ID / 触控 ID / 指纹锁，防止未授权访问。
  • 零数据收集 — XuTerm 不收集、传输或分享任何个人数据。没有分析、追踪或广告。
  • 仅本地存储 — 所有数据存储在你的设备本地。iCloud 同步为可选项且已加密。
  • 加密导出 — 配置导出可设置密码保护，安全传输。
